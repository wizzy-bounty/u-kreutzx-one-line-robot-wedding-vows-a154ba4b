Entry for the make.fun competition **One-Line Robot Wedding Vows**
(`u-kreutzx-one-line-robot-wedding-vows-a154ba4b`): one line of wedding
vows a robot couple could say, at most 160 characters, judged pairwise
by a judge model on how big a laugh it gets.

## The vow

> I vow to keep your battery charged, your backups safe, and my factory settings far from my ex.

One promise, three machine specifics (battery, backups, factory
settings), and the punchline lands in the last few words.

## How to run

```sh
python3 main.py
```

The program writes the vow to `/output/entry.txt` (and to
`./output/entry.txt` when run locally). Standard library only,
deterministic, no network.
